## v2.1（0.3.0，用户 2026-10-29 试用 0.2.0 后的 7 条反馈，按用户给的顺序）

> 反馈原文的要点：① 看屏幕最要紧的是隐私（密码、邮件、交易、QQ 微信聊天），而且希望她主动说，不想记快捷键；看得有点慢。
> ② 想要打开软件就检测更新并提示。③ 聊天里就能设提醒、开游戏；鼠标交互重做（摸头不弹聊天框、拖动不弹聊天框、右键 / 按住右键在头顶浮出气泡选项）；多一些彩蛋。
> ④ 找一些贴图放到根目录给用户挑（代码暂时不做）。⑤ 界面更精美，每个角色一套自己的界面（先做千秋）。⑥ 语音（千秋的声音，只读精简后的部分，不同场景有不同语音）。
> ⑦ 和千秋对战的下落方块游戏（最后做），所有游戏的界面也要精美。

### P9 看一眼：隐私护栏、主动看、更快（DECISIONS #47）
- [x] 看之前：聊天软件、邮件、支付 / 证券、远程桌面、系统凭据窗口一律不看；标题里有登录、密码、邮箱、支付、订单、转账、验证码、身份证等的窗口不看；焦点在密码框时不看
- [x] 截什么：只截前台那一个窗口（不截整个屏幕、旁边的窗口、任务栏）；前台是 DeskMate 自己时看它后面那个窗口
- [x] 发之前：本地文字识别（Windows 自带 OCR，不联网）把邮箱、手机号、证件号、卡号、金额、长数字、像密钥的字符串、带「密码 / 验证码 / 账号」的那一行涂黑；她主动看时发现这类内容就干脆不看
- [x] 透明：气泡下面一行小字「看了 XX · 遮住 N 处」；设置里「预览她会看到什么」（只在本机显示，不发送）；本次运行的看画面记录（不存图）
- [x] 主动看：打开「看屏幕」后，玩游戏时默认偶尔看一眼（不用再一个个勾游戏，可以排除某些游戏），看视频 / 写代码 / 写东西可选；间隔和每天上限
- [x] 更快：JPEG（体积约为 PNG 的 1/3）、按快捷键后马上说一句「我看看～」、输出更短
- [x] 测试 + 本机冒烟 + 安全复查

### P10 检查更新（DECISIONS #48）

- [ ] 下载并安装：只从 GitHub 下载对应的安装包，校验大小和 SHA-256，用户点了才运行安装程序，DeskMate 先退出

### P11 对话驱动 + 鼠标交互重做（DECISIONS #49）

- [ ] 左键：点身体 = 聊天；点头或在头上来回蹭 = 摸头；拖动不弹聊天框；按住不动有反应

- [ ] 聊天里说就能做：玩某个游戏（直接打开）、设提醒（更多说法）、问有哪些提醒、勿扰、隐藏、看一眼、打开设置 / 日记；本地识别优先，模型用动作标记兜底
