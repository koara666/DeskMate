# 需要你（用户）来做的事

> 这里只列「只有你能做」的事情：登录账号、填写 API Key、提供图片、公开发布、花钱。
> 每一项都写了具体步骤，不需要懂编程。做完后在该项前面把 `[ ]` 改成 `[x]`（或者直接告诉 agent「某某已完成」）。
> 这些都**不着急**：不做的话，程序也能用 mock（假数据）模式运行。

## 待办

### [ ] 0. 安装 DeskMate（想用的时候）
- **为什么**：程序已经可以用了，安装需要你本人双击确认。
- **怎么做**：
  1. 打开文件夹 `D:\DeskMate\src-tauri\target\release\bundle\nsis\`，双击 `DeskMate_0.1.0_x64-setup.exe`。
  2. 如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（安装包没有购买数字签名才会这样提示）。
  3. 安装完桌面右下角会出现小鲸鱼。使用说明见项目根目录的 `README.md`。
- **说明**：开发期间 agent 测试时用的是临时数据目录，不会影响你安装后的数据。

### [ ] 1. 填写至少一个聊天模型的 API Key（想真正聊天时再做）
- **为什么**：没有 Key 时角色只能用 mock 模式回复测试文字。Key 相当于付费账号的密码，只能由你本人申请和填写。
- **推荐**：DeepSeek（便宜、中文好、国内直接能用）。
- **怎么做**：
  1. 打开 https://platform.deepseek.com ，注册并登录，充值一点余额（几块钱就能聊很久）。
  2. 左侧找到「API Keys」，点「创建 API Key」，复制那一串以 `sk-` 开头的字符。
  3. 在 DeskMate 里：右键点角色 →「设置…」→「模型」→ 展开「DeepSeek」→ 把 Key 粘贴到输入框 → 点「保存 Key」。
  4. 点「测试连接」，看到「连接成功」就好了。
  5. 页面最上面「日常聊天使用」选「DeepSeek」。
- **安全说明**：Key 只保存在 Windows 自带的「凭据管理器」里，不会写进任何文件，界面上只显示最后 4 位。不要把 Key 发给任何人（包括聊天里发给角色）。
- 想用 Gemini 或 Claude 也一样，在对应卡片里填写；它们在国内通常需要开代理。

### [ ] 2. 把代码备份到 GitHub（私有仓库）——需要你登录一次
- **为什么**：需求要求代码放到 GitHub 的**私有**仓库。登录 GitHub 必须由你本人完成。目前代码只在本机 `D:\DeskMate` 里（已经用 git 保存了每一步的历史）。
- **怎么做**：
  1. 安装 GitHub 命令行工具：打开「开始菜单」→ 搜索「PowerShell」→ 打开后输入 `winget install GitHub.cli` 回车，等它装完，关掉窗口。
  2. 重新打开 PowerShell，输入 `gh auth login` 回车，按提示选择：`GitHub.com` → `HTTPS` → `Login with a web browser`，然后在浏览器里登录并输入屏幕上显示的验证码。
  3. 告诉 agent「GitHub 已登录」。agent 会创建一个**私有**仓库并推送（不会设成公开，也不会发布 Release）。
- **注意**：你电脑的 git 设置了代理 `127.0.0.1:7897`。推送时如果代理软件没开，可能会连不上——推送前请打开代理软件，或者告诉 agent。

### [ ] 3. （可选）给角色换上你自己的图片
- **为什么**：仓库里只能放原创的简单占位形象（角色大多是别人的版权作品，不能把官方图片放进 GitHub）。你自己电脑上用什么图片由你决定，程序会优先用你的图片，而且这些图片不会进入仓库。
- **怎么做**：
  1. 右键点角色 →「设置…」→ 左边选「角色」→ 点要换图的角色卡片。
  2. 点「打开图片文件夹」，会打开 `%APPDATA%\DeskMate\characters\<角色id>\assets\` 这个文件夹。
  3. 把图片放进去，按状态命名：
     - `idle.png` 待机（**最重要**，只放这一张的话所有状态都用它）
     - `talking.png` 说话、`thinking.png` 思考、`happy.png` 开心、`sad.png` 难过/困惑、`sleep.png` 睡觉（都可选）
  4. 回到设置窗口点「重新加载」，桌面上的角色就换好了。
- **图片建议**：PNG（背景透明效果最好），也支持 WebP / GIF / JPG；单张不超过 5 MB；推荐大约 320×360 像素，角色站在画面底部中间。

### [ ] 4. （可选）第一次使用「任务执行」时帮忙验证一下
- **为什么**：开发时按规定不能用你的额度跑真实任务，所以「交给 Claude Code / Codex 执行」这部分只用模拟数据测试过。第一次真实使用时请顺便确认它工作正常。
- **怎么做**：
  1. 确认已经登录：打开「开始菜单」→ 搜索「PowerShell」打开 → 输入 `claude` 回车，按提示登录一次后输入 `/exit` 退出（用 Codex 的话输入 `codex` 登录）。
  2. 在 `D:\DeskMate-Work` 文件夹里新建一个文本文件，随便写几行字。
  3. 在聊天里点 🛠，任务写「统计这个文件夹里每个文本文件有多少字」，点「开始执行」。
  4. 能看到执行步骤、最后角色告诉你结果，就说明一切正常。如果报错，把「查看详情」里的内容告诉 agent。
- 设置 →「任务执行」里能看到检测结果、每次任务的记录和日志。

### [ ] 5. （可选，要花钱）给安装包购买代码签名证书
- **为什么**：没有签名的安装包，Windows 会显示「未知发布者」并拦一下（点「仍要运行」即可）。签名后提示会消失。证书每年要几百到上千元，所以这一步由你决定，不做也完全不影响使用。
- **怎么做**：向 DigiCert / Sectigo 等机构购买「代码签名证书」，拿到后告诉 agent，agent 会把签名配置进打包流程。
