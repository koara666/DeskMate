# 需要你（用户）来做的事

> 这里只列「只有你能做」的事情：登录账号、填写 API Key、提供图片、公开发布、花钱。
> 每一项都写了具体步骤，不需要懂编程。做完后在该项前面把 `[ ]` 改成 `[x]`（或者直接告诉 agent「某某已完成」）。

### [ ] 1. 填写至少一个聊天模型的 API Key（想真正聊天时再做）
- **为什么**：没有 Key 时角色只能用 mock 模式回复测试文字。Key 相当于付费账号的密码，只能由你本人申请和填写。
- **推荐**：DeepSeek（便宜、中文好、国内直接能用）。
- **怎么做**：
  1. 打开 https://platform.deepseek.com ，注册并登录，充值一点余额（几块钱就能聊很久）。
  2. 左侧找到「API Keys」，点「创建 API Key」，复制那一串以 `sk-` 开头的字符。
  3. 在 DeskMate 里：右键点角色 →「设置…」→「模型」→ 展开「DeepSeek」→ 把 Key 粘贴到输入框 → 点「保存 Key」。
  4. 点「测试连接」，看到「连接成功」就好了。
  5. 页面最上面「日常聊天使用」选「DeepSeek」。
- **安全说明**：Key 只保存在 Windows 自带的「凭据管理器」里，不会写进任何文件，界面上只显示最后 4 位。不要把 Key 发给任何人（包括聊天里发给角色）。
- 想用 Gemini 或 Claude 也一样，在对应卡片里填写；它们在国内通常需要开代理。

### [ ] 3. （可选）给角色换上你自己的图片
- **为什么**：仓库里只能放原创的简单占位形象（角色大多是别人的版权作品，不能把官方图片放进 GitHub）。你自己电脑上用什么图片由你决定，程序会优先用你的图片，而且这些图片不会进入仓库。
- **怎么做**：
  1. 右键点角色 →「设置…」→ 左边选「角色」→ 点要换图的角色卡片。
  2. 点「打开图片文件夹」，会打开 `%APPDATA%\DeskMate\characters\<角色id>\assets\` 这个文件夹。
  3. 把图片放进去，按状态命名：
     - `idle.png` 待机（**最重要**，只放这一张的话所有状态都用它）
     - `talking.png` 说话、`thinking.png` 思考、`happy.png` 开心、`sad.png` 难过/困惑、`sleep.png` 睡觉（都可选）
  4. 回到设置窗口点「重新加载」，桌面上的角色就换好了。
- **图片建议**：PNG（背景透明效果最好），也支持 WebP / GIF / JPG；单张不超过 5 MB；推荐大约 320×360 像素，角色站在画面底部中间。

  4. 能看到执行步骤、最后角色告诉你结果，就说明一切正常。如果报错，把「查看详情」里的内容告诉 agent。

### [ ] 7. （可选）提供原作材料，让红莉栖、千秋「炼化」得更像原作
- **为什么**：现在的人设是 agent 根据资料用自己的话写的，模型知道「她是什么样的人」，但没见过她真正怎么说话。有了原作的台词，agent 可以：① 统计她说话的习惯写进人设；② 挑出最有代表性的原作对话片段做成「台词库」，聊天时给模型当语气参考。这是 agent 能「炼化」的前提，但原作材料只能由你来提供。（为什么不训练 / 微调模型，见 DECISIONS #31。）
- **准备什么**（任选，越多越好；中文最好，日文、英文也可以）：
  - 最好：**游戏剧本文本**（每句台词前面写着谁在说话的那种）。
  - 也很好：小说、漫画的文字版。
  - 也可以：**动画字幕文件**（`.ass` / `.srt`）。字幕不写是谁在说话，agent 会根据上下文判断，拿不准的会丢掉。
  - 也可以：网页上的台词集、语录页（浏览器里按 `Ctrl+S` 存下来，或者把文字复制进一个 `.txt` 文件）。
  - 红莉栖：《命运石之门》游戏或动画，剧场版、《命运石之门 0》里她出场的部分也可以。
  - 千秋：《超级弹丸论破2》游戏，动画《弹丸论破3》（绝望篇里是人类千秋，希望篇里也有她）。
- **放到哪里**：
  1. 按 `Win + E` 打开文件资源管理器，在最上面的地址栏输入 `%APPDATA%\DeskMate` 然后按回车。
  2. 在这里新建一个文件夹，名字叫 `corpus`。
  3. 进入 `corpus`，再新建两个文件夹：`makise-kurisu`（红莉栖）、`nanami-chiaki`（千秋）。只想做一个的话建一个就行。
  4. 把材料放进对应的文件夹。文件名随便起，可以有子文件夹；压缩包请先解压。
- **然后**：告诉 agent「语料放好了，炼化红莉栖」（或千秋）。agent 会筛出她的台词、改进人设、做好台词库并重新安装。完成后打开 设置 →「角色」→ 点她的卡片，能看到「已加载原作台词库：常驻 N 段……」。
- **说明**：
  - 这些材料和做好的台词库只在你自己电脑里（`%APPDATA%\DeskMate`），不会上传到 GitHub（仓库是公开的）。
  - 炼化是 agent 在开发时做的，用的是你运行 agent 的那份额度；材料很多时会多用一些（agent 会先用程序筛掉无关内容，不会整本整本地读）。
  - 聊天时每轮大约多带 1000 token 的常驻台词。它在可以缓存的部分，缓存命中时按原价的十分之一左右计费，所以多花的钱很少。
  - 不准备材料也完全没关系，现在的人设照常能用。
