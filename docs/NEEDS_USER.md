### [ ] 7. （可选）提供原作材料，让红莉栖「炼化」得更像原作（七海千秋 2026-10-28 已用你的游戏文件炼化完成）
- **为什么**：现在的人设是 agent 根据资料用自己的话写的，模型知道「她是什么样的人」，但没见过她真正怎么说话。有了原作的台词，agent 可以：① 统计她说话的习惯写进人设；② 挑出最有代表性的原作对话片段做成「台词库」，聊天时给模型当语气参考。这是 agent 能「炼化」的前提，但原作材料只能由你来提供。（为什么不训练 / 微调模型，见 DECISIONS #31。）
- **最省事的做法（先看这个）**：需要的量很小——每个角色有几集字幕或几章剧本就够，不用把整部作品都准备齐。2026-10-28 查过，网上**没有现成的红莉栖 / 千秋台词集**，能找到的是：GitHub 上的动画字幕文件（命运石之门；弹丸论破3 的没找到）、和从游戏文件里导出剧本的开源工具（命运石之门：`Ukinchou/steins-gate-REBOOT-bilingual-subtitles`、`Daviex/Steins-Gate-Dialogues-Extractor`；弹丸论破 2：`morgana-x/danganronpa-lin-compiler-v2`，都要有游戏本体）。所以：
  1. agent 先自己去 GitHub 等公开位置下载动画字幕（放在 `corpus/` 里，你不用动手）。
  2. 如果你电脑里有这两款游戏（Steam 版《STEINS;GATE》《弹丸论破 1·2 Reload》），告诉 agent，agent 用开源提取工具从你自己的游戏文件里导出带说话人名字的文本——这是质量最好的来源，你也不用动手。
  3. 只有以上都不行，才需要你自己按下面的方式放材料。
- **准备什么**（任选，越多越好；中文最好，日文、英文也可以）：
  - 最好：**游戏剧本文本**（每句台词前面写着谁在说话的那种）。
  - 也很好：小说、漫画的文字版。
  - 也可以：**动画字幕文件**（`.ass` / `.srt`）。字幕不写是谁在说话，agent 会根据上下文判断，拿不准的会丢掉。
  - 也可以：网页上的台词集、语录页（浏览器里按 `Ctrl+S` 存下来，或者把文字复制进一个 `.txt` 文件）。
  - 红莉栖：《命运石之门》游戏或动画，剧场版、《命运石之门 0》里她出场的部分也可以。
  - 千秋：《超级弹丸论破2》游戏，动画《弹丸论破3》（绝望篇里是人类千秋，希望篇里也有她）。
- **放到哪里**：
  1. 按 `Win + E` 打开文件资源管理器，在最上面的地址栏输入 `%APPDATA%\DeskMate` 然后按回车。
  2. 在这里新建一个文件夹，名字叫 `corpus`。
  3. 进入 `corpus`，再新建两个文件夹：`makise-kurisu`（红莉栖）、`nanami-chiaki`（千秋）。只想做一个的话建一个就行。
  4. 把材料放进对应的文件夹。文件名随便起，可以有子文件夹；压缩包请先解压。
- **然后**：告诉 agent「语料放好了，炼化红莉栖」（或千秋）。agent 会筛出她的台词、改进人设、做好台词库并重新安装。完成后打开 设置 →「角色」→ 点她的卡片，能看到「已加载原作台词库：常驻 N 段……」。
- **说明**：
  - 这些材料和做好的台词库只在你自己电脑里（`%APPDATA%\DeskMate`），不会上传到 GitHub（仓库是公开的）。
  - 炼化是 agent 在开发时做的，用的是你运行 agent 的那份额度；材料很多时会多用一些（agent 会先用程序筛掉无关内容，不会整本整本地读）。
  - 聊天时每轮大约多带 1000 token 的常驻台词。它在可以缓存的部分，缓存命中时按原价的十分之一左右计费，所以多花的钱很少。
  - 不准备材料也完全没关系，现在的人设照常能用。
