# DeskMate 0.3.2

- **七海千秋说日语了**：「设置 → 声音 → 她说话的语言」默认是日语。气泡照常显示中文，声音说日语，像看番的中文字幕。
  - 她的每一句预写台词都有日语版；聊天回复由模型顺便附上日语（不多花一次请求）；都没有的时候，用你的聊天模型把要念的那一两句翻成日语（计入主动行为的每日上限），翻译不了就念中文。
  - 想听中文就选「中文」。
- **GPT-SoVITS 声音更好用**：可以接用她的游戏原声训练出来的模型（在你自己电脑上运行，免费、不联网）；念日语、念中文会自动告诉它用哪种语言。
- **Windows 自带的语音**：说日语时自动挑日语的声音；电脑上没装日语语音就改念中文。

0.3.1 的内容见上一个版本：七海千秋的 Q 版形象和反应表情。

安装：下载下面的 `DeskMate_0.3.2_x64-setup.exe` 双击安装；已经装了 0.3.x 的，打开 DeskMate 后她会提示更新。
