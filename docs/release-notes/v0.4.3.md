# DeskMate 0.4.3

这一版让七海千秋换上了 Q 版小人的新形象。

## 新的

- **千秋的 Q 版形象**：安装或更新后，千秋就直接是 Q 版小人了，23 个表情和动作（待机、说话、开心、被摸头、晕、鼓脸、害羞、睡觉、输赢……），不需要你下载或放任何文件。以前安装包里只有一套代码画的简单形象，很多人反馈不像。如果你自己在角色图片文件夹里放过图，仍然优先用你自己的。
- 形象图是用户生成的原创同人图，和游戏官方无关；如果版权方有异议会撤下，之后的安装包就不再带。

## 说明

- 0.4.2 的内容见上一个版本：声音跟得上文字、游戏玩得快时不再连着念一串、问别的城市的天气、她会自己判断要不要上网查。
- 内部：发布流程提速了（同一个提交不再重复构建三次，依赖缓存共用，发布时不再重跑测试）。

安装：下载下面的 `DeskMate_0.4.3_x64-setup.exe` 双击安装；已经装了 0.4.2 的，打开 DeskMate 后她会提示更新。
