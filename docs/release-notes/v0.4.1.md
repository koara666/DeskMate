# DeskMate 0.4.1

小修补，主要是声音设置页的一处容易让人困惑的地方。

## 修好的

- **「只有试听有声音，别的地方都没声音」**：这不是出了故障，而是「设置 → 声音」里的总开关「让她出声」没勾——试听不看这个开关，所以引擎配好了试听也能响，但聊天、播报、游戏、摸头时她都是安静的。以前界面上没有任何提示。现在选了引擎但总开关没开时，页面最上面会用醒目的提示写明「现在只有试听会出声」，旁边有「现在打开」按钮；点了「试听一句」成功后，提示语也会提醒你总开关还没打开。
- **联网搜索更不容易干等**：网络连不上时，以前最多会等约 20 秒才告诉你没查到，现在最多约 15 秒；等的时候桌宠会显示「在想」的样子。

## 说明

- 0.4.0 的内容见上一个版本：联网搜索、海龟汤 / 二十问现场出题、声音覆盖更多场合、拖动不再笑、方块对战更公平。

安装：下载下面的 `DeskMate_0.4.1_x64-setup.exe` 双击安装；已经装了 0.4.0 的，打开 DeskMate 后她会提示更新。
