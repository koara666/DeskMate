# DeskMate 0.4.0

这一版把你反馈的问题都修了，并且让声音覆盖到更多地方。

## 新的

- **她能上网查东西了**：问新闻、最新消息、比分、股价，或者直接对她说「搜一下……」「帮我查一下……」，她会先上网查，再用自己的话告诉你，气泡下面会写明「上网查了什么」。
  - 新闻用 Google 新闻，其他用 DuckDuckGo，查不到再用维基百科；不用注册、不用 Key。
  - **只发搜索关键词**，不发聊天记录和记忆；带邮箱、手机号、密码这类内容的话不会拿去搜。
  - 默认打开，不想要就到「设置 → 模型」里关掉「允许她上网搜索」。
- **海龟汤、二十问每局都是新题**：模型每局现场原创一道，不会再玩完；内置题库只在没网络时备用。每道题都带一份「是 / 不是」事实清单，她回答时必须照着答。
- **声音覆盖更多场合**：每日播报、很久没聊天的招呼、主动搭话、游戏胜负反应，开着日语语音时模型会顺便写好日语（不再多花一次翻译请求）；海龟汤 / 二十问里她的「是 / 不是 / 无关……」也用日语说出来；日语对照记在本地，重启以后提醒到点也能直接念日语。

## 修好的

- **拖她的时候不再笑**：以前她说完任何一句话都会笑一下，所以拖她、戳她、甩晕她时也会傻笑。现在有专属表情的反应说完后回到平常，摸头还是会笑；拖着的时候一直是惊讶的样子，松手才换回来。
- **方块对战更公平**：她的速度降到人手能做到的范围（困难档每块约 1 秒，以前只要 0.5 秒），难度按钮上写明了每块大概几秒；对局中也显示按键提示（空格是直接落下，她也一样）。
- **海龟汤 / 二十问不再答反**：比如谜底是跳绳，问「是不是电脑或手机上的游戏」，现在会答「不是」。

## 说明

- 搜索用的是公开的网页接口，在中国大陆可能连不上 DuckDuckGo / Google；连不上时她会如实说没查到，不会编。

安装：下载下面的 `DeskMate_0.4.0_x64-setup.exe` 双击安装；已经装了 0.3.x 的，打开 DeskMate 后她会提示更新。
