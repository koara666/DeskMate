# DeskMate 0.4.2

这一版主要修「声音和文字对不上」，另外让她联网更像一个真正会上网的小助手。

## 声音

- **不再姗姗来迟**：以前要等整条回复写完才开始合成声音，现在她写到第一句话（日语语音是回复开头那一行）就开口了，文字和声音基本同步。用本机 GPT-SoVITS 时，启动后会先预热一下模型，第一句话也不会再晚二十秒。
- **不再连着念一长串**：现在只念「最新的一句」，新的一句出来，还没念的旧句子直接作废；等太久（文字早就看完了）的也不念。猜拳这类游戏玩得快时，开局、每一轮的随口一句会自己安静，只念最后的胜负；玩得慢才会说中间的话。
- **没那么急促**：上一句快念完了会等它念完、喘口气再说下一句，不再硬切；你一开口、点停止或关掉声音，她马上闭嘴。
- 修了一处可能让两条声音叠在一起的小问题。

## 联网

- **问别的城市的天气**：以前设置里的城市表没有的地方（比如抚顺）会被当成「查不到」。现在先去查它的位置再给真实天气，查不到再上网搜；联网关着就老实说查不了，不会拿你设置里那个城市的天气顶替。
- **她会自己判断要不要上网**：除了新闻、比分、「搜一下……」这些，遇到她不确定、需要最新信息才答得准的事（价格、最近发生的事、不熟悉的人或作品……），她会自己去搜再回答。闲聊不会搜；气泡下面照样写明搜了什么；设置 → 模型里可以整体关掉。

## 说明

- 日语语音时，她的回复开头那一行日语不会显示在气泡里（和以前一样），只是现在写在最前面。
- 自己决定要搜的那一次，会比平时多一次聊天调用。

安装：下载下面的 `DeskMate_0.4.2_x64-setup.exe` 双击安装；已经装了 0.4.1 的，打开 DeskMate 后她会提示更新。
