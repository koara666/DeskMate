# DeskMate 0.3.0

这一版按试用反馈做了这些改动：

- **看屏幕更注意隐私**：聊天软件（QQ、微信……）、邮件、支付和证券软件、远程桌面、登录 / 密码 / 账户 / 订单页面一律不看；正在输密码时不看；只截你正在用的那一个窗口；发出去之前在本机用 Windows 自带的文字识别把邮箱、手机号、卡号、金额、密钥和带「密码」的行涂黑。设置里可以预览她会看到什么。
- **她会主动看了**：打开「看屏幕」后，你玩游戏时她偶尔看一眼、说句话（可以排除某些游戏）；按快捷键时先说一句「我看看」，回得更快。
- **检查更新**：打开后会去 GitHub 查有没有新版本，有的话她会告诉你，点一下就下载、校验、安装（可以在「设置 → 关于」里关掉）。
- **聊天里说就能做**：「来一局井字棋」「半小时后提醒我收衣服」「明天 7 点叫我起床」「别打扰我」「你先躲一下」「我有哪些提醒」……
- **鼠标交互重做**：点身体聊天；点头或在头上蹭蹭是摸头，不会弹出聊天框；拖动不弹聊天框；右键（也可以按住右键拖到气泡上松开）头顶冒出选项气泡；她主动说话时只弹一个小气泡，点一下才变成聊天框；还藏了不少彩蛋。
- **千秋专属的掌机风界面**，小游戏也换了新样子。
- **她能出声了**（默认关闭）：Fish Audio 上有现成的七海千秋声音，有免费档；也可以用 Windows 自带的语音或自己的 GPT-SoVITS。只读开头一两句。
- **新游戏「方块对战」**：和千秋同时玩下落方块，消行给对方塞垃圾行。

安装：下载下面的 `DeskMate_0.3.0_x64-setup.exe` 双击安装。已经装了旧版的直接覆盖安装，聊天记录、记忆、Key 都在。
