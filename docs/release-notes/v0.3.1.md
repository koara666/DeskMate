# DeskMate 0.3.1

- **七海千秋有了自己的 Q 版形象**：抱着游戏机的小千秋，一共 22 种表情和动作（全部原创绘制）。
- **反应会换表情**：摸头会害羞、甩她会晕、连戳会鼓脸、躲起来和开勿扰会戴上猫耳兜帽、刚被戳醒会揉眼睛、小游戏输赢有不同的样子；夜里会犯困，下雨天和冬天戴着兜帽。
- 你也可以放自己的图片替换任何一张（`pat.png`、`dizzy.png`……，见 README「换角色、换形象」）。

0.3.0 的内容见上一个版本：看屏幕的隐私保护、检查更新、聊天里直接开游戏 / 设提醒、头顶气泡菜单、掌机风界面、语音、方块对战。

安装：下载下面的 `DeskMate_0.3.1_x64-setup.exe` 双击安装；已经装了 0.3.0 的，打开 DeskMate 后她会提示更新。
