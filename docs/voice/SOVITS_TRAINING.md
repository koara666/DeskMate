# 用自己的服务器训练千秋的声音（GPT-SoVITS）

> 写给 DeskMate 的用户（不需要会编程，但要会在服务器上照着敲命令）。对应 NEEDS_USER #13、ROADMAP v2.2。
> 原声、训练出来的模型都只放在你自己的电脑和服务器上，**不要放进 DeskMate 的仓库**（公开仓库）。

## 为什么现在的声音不像

- 默认的 Fish Audio「千秋」是别人上传的社区声音，素材和质量都不可控。
- 它是用日语素材克隆的，DeskMate 现在让它念**中文**，音色和口音都会跑偏。
- 「Windows 自带语音」本来就是系统的朗读声音，不可能像她。

最像的办法：用千秋的日语原声自己训练，让她**说日语**（中文字幕照常显示在气泡里）。想让她说中文也可以，GPT-SoVITS 能用日语训练的声音说中文，但会带一点口音。

## 会不会变重

不会。模型跑在你的 4090 服务器上，DeskMate 只是把一两句话发过去、拿回一小段音频（还会缓存，同一句话第二次不再请求）。安装包、内存、CPU 都不变。

## 第 1 步：准备原声（3~10 分钟就够）

1. 从你自己的《超级弹丸论破 2》游戏文件里找到千秋的日语语音（P12 取立绘时已经确认游戏里有日语原声）。
2. 挑**干净**的句子：只有她一个人在说、没有背景音乐和音效、情绪平稳的优先（太激动、太小声的少放）。
3. 总长 3~10 分钟。太短像得不够，再长提升不大。

## 第 2 步：在服务器上装 GPT-SoVITS

1. 按官方仓库 https://github.com/RVC-Boss/GPT-SoVITS 的 README 安装（Linux 用它的安装脚本；Windows 服务器可以直接下载整合包）。以官方 README 为准，版本选最新的稳定版。
2. 启动网页界面（README 里写的 `webui.py` 或整合包里的启动脚本），在浏览器里打开它给的地址。

## 第 3 步：处理素材 → 训练

都在网页界面里点，按页面上的顺序：

1. **人声分离 / 去混响**（UVR5）：如果素材里有背景音，先过一遍。
2. **语音切分**：把长音频切成一句一句。
3. **语音识别（ASR）**：语言选**日语**，自动生成每句话的文字。
4. **校对**：打开标注工具，把识别错的字改对（这一步决定发音准不准，值得花时间）。
5. **训练集格式化**：一键。
6. **微调训练**：先训练 SoVITS 模型，再训练 GPT 模型，参数先用默认值。4090 上一般十几到几十分钟。
7. **推理**：在网页里选刚训练好的两个模型，挑一句干净的原声做参考音频，试着合成几句日语和中文，听听像不像。不像就回到第 4 步多校对、或者换更干净的素材。

记下来：两个模型文件的路径、你最满意的那句参考音频的**服务器上的路径**和**这句话的日语原文**。

## 第 4 步：在服务器上开声音服务

在 GPT-SoVITS 目录运行（只监听服务器本机，不对外网开放）：

```
python api_v2.py -a 127.0.0.1 -p 9880
```

然后在浏览器或命令行里调用一次（把路径换成第 3 步记下的模型路径），让它用你训练的模型：

```
http://127.0.0.1:9880/set_gpt_weights?weights_path=<GPT 模型路径>
http://127.0.0.1:9880/set_sovits_weights?weights_path=<SoVITS 模型路径>
```

（服务器上用 `curl "<上面的地址>"` 就行。具体参数以 `api_v2.py` 文件开头的说明为准。）

## 第 5 步：让 DeskMate 连上

现在的 DeskMate 出于安全只连本机地址，所以用 SSH 把服务器的 9880 端口「搬」到你电脑上：

1. 在**你自己的电脑**上打开命令行（PowerShell），运行：
   ```
   ssh -L 9880:127.0.0.1:9880 你的用户名@服务器地址
   ```
   登录后让这个窗口一直开着（关掉就断了）。
2. DeskMate「设置 → 声音」：
   - 引擎选 **GPT-SoVITS**；
   - 接口地址 `http://127.0.0.1:9880`；
   - 「参考音频」：填**服务器上**那句原声的路径；「参考音频说的话」：这句话的日语原文；「参考音频的语言」：日语；
   - 点「试听」。
3. 想让她说日语：等 v2.2 的「声音语言」做好后，在声音页选「日语」（气泡里还是中文）。

## 常见问题

- **试听没声音**：先看 SSH 窗口还开着没有；再在服务器上看 `api_v2.py` 的输出有没有报错（多半是参考音频路径不对，或者参考音频不在 3~10 秒之间）。
- **发音怪**：回到第 3 步第 4 小步，把识别文字校对仔细。
- **声音发抖、有杂音**：素材不干净，去掉有背景音的句子重新训练。
