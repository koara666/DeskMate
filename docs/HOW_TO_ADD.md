角色包结构：
```
characters/<角色id>/
  character.json   # 名字、语言、表情映射、作者、版本
  persona.md       # 性格设定 + 5~10 段原创示范对话
  assets/          # 仓库里只放原创占位 SVG；用户图片放用户数据目录
```

## 3. 新增功能的一般步骤
