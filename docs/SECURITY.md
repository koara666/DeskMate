# 安全模型与威胁清单

> 安全是最高优先级。每个里程碑结束时复查本文件，更新「状态」和「代码位置」。
> 状态：✅ 已实现并有测试 / 🟡 部分实现 / ⬜ 计划中

## 1. 资产
- 用户的 API Key（DeepSeek / Gemini / Anthropic 等）
- 用户的记忆数据库（个人信息、对话摘要）
- 用户电脑上的文件（任务执行时可被修改）
- 用户的钱（API 用量、订阅额度）
