# 安全模型与威胁清单

> 安全是最高优先级。每个里程碑结束时复查本文件，更新「状态」和「代码位置」。
> 状态：✅ 已实现并有测试 / 🟡 部分实现 / ⬜ 计划中

## 1. 资产
- 用户的 API Key（DeepSeek / Gemini / Anthropic 等）
- 用户的记忆数据库（个人信息、对话摘要）
- 用户电脑上的文件（任务执行时可被修改）
- 用户的钱（API 用量、订阅额度）

## 2. 威胁清单

| # | 威胁 | 防护措施 | 代码位置 | 状态 |
|---|---|---|---|---|
| T1 | **密钥泄露**：明文落盘、进日志、进 git、被前端/模型拿到 | Key 只存 Windows 凭据管理器；前端只拿到末 4 位；HTTP 错误信息脱敏后再显示/记录；日志不记录请求头和请求体；gitleaks pre-commit + CI；.gitignore 排除 .env、*.db 等 | （实现后填写） | ⬜ |
| T2 | **提示注入**：网页/文件/任务结果里夹带「忽略之前的指令」 | 不可信内容放在明确标注的区块里并告知模型其为数据；对话模型没有任何工具权限；任务执行必须经用户确认；不可信内容不能修改角色设定和记忆指令 | | ⬜ |
| T3 | **记忆投毒**：不可信来源的内容被当作指令或用户偏好写入记忆 | 记忆条目记录来源类型（chat/task/file/web/user_edit）；非 chat/user_edit 来源只能作为「带来源的事实」且标记不可信；提取提示词要求只记录事实；写入前敏感信息过滤（Key、密码、验证码、证件号、银行卡号） | | ⬜ |
| T4 | **误删文件 / 越权访问** | 执行 agent 限定在工作目录；CLI 权限/沙盒参数 + 程序侧路径检查（规范化路径、拒绝 `..`、符号链接逃逸、系统目录）；删除、目录外访问、联网、安装、执行未知脚本需弹窗确认；默认工作目录是 D 盘专用文件夹 | | ⬜ |
| T5 | **超额花费** | 每日/每月花费上限，调用前检查；每个任务时间与花费上限；后台记忆整理用最便宜模型；开发与测试只用 mock | | ⬜ |
| T6 | **恶意角色包** | id 白名单字符、文件大小上限、只读取固定文件名（不跟随路径）、图片校验文件头；persona 只作为纯文本进入提示词，永不作为 HTML 渲染；角色包不能包含可执行内容 | | ⬜ |
| T7 | **WebView 注入（XSS）**：模型输出里含 `<script>` 等 | Preact 文本转义，禁止 `dangerouslySetInnerHTML`；严格 CSP（`default-src 'self'`，无 `unsafe-eval`）；不加载远程网页；capabilities 最小化 | | ⬜ |
| T8 | **订阅令牌滥用** | 只调用官方 `claude` / `codex` 命令行；不读取、不复制其登录文件；每个用户用自己的账号 | | ⬜ |
| T9 | **数据丢失**：升级或损坏导致记忆丢失 | 迁移前自动备份；每日备份保留 7 份；启动时完整性检查，损坏则从最近备份恢复 | | ⬜ |
| T10 | **隐私外泄** | 无遥测、无自动更新；只连接用户配置的模型接口；日志不含对话内容 | | ⬜ |
