# DeskMate 桌面伙伴

一个住在电脑桌面角落、像朋友一样陪着你的小伙伴：陪你聊天、记得你说过的事，偶尔关心你一下。它是陪伴型的桌宠，不是干活的助手——真要写代码、整理一大堆文件，直接用 Claude Code 或 Codex 更合适（DeskMate 仍保留了「委托外部 agent」作为默认关闭的高级选项）。

> 内置 8 个角色：鲸鱼娘、奶龙、奶蛙、牧濑红莉栖、椎名真由理、七海千秋、不二咲千寻、结衣。
> 同人角色的设定和示范对话都是原创的，和官方无关；仓库里只带简单的原创占位形象，你可以换成自己喜欢的图片。
> 牧濑红莉栖和七海千秋带有原作经历：她们记得自己的过去（研究所的大家、日向君……），聊到相关的人和事时会自然地想起来。

## 一、安装

1. 找到安装包：`DeskMate_<版本号>_x64-setup.exe`（目前在 `D:\DeskMate\src-tauri\target\release\bundle\nsis\` 文件夹里）。
2. 双击运行。因为安装包没有购买数字签名，Windows 可能会提示「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**。
3. 安装只需要几秒，装在你自己的用户目录下，不需要管理员权限。
4. 安装完会自动启动，桌面右下角出现一只小鲸鱼。

> 需要 Windows 10 / 11。程序依赖系统自带的 WebView2（Win11 自带；Win10 如果没有，安装程序会自动下载）。

## 二、第一次使用

- 第一次启动时，角色旁边会自动弹出一个气泡，告诉你怎么用（只出现一次）。
- **左键点角色**：打开 / 收起聊天框。**右键点角色**：菜单（换角色、停靠位置、勿扰、设置、退出）。
- **按住角色拖动**：可以放在屏幕任何地方，靠近边缘会自动贴边。
- 一开始是「测试模式」（mock）：角色会回复固定的测试文字，不联网也不花钱。想真正聊天，需要填一个模型的 API Key：

### 填 API Key（推荐 DeepSeek，便宜、中文好、国内能直接用）
1. 打开 <https://platform.deepseek.com>，注册登录，充一点钱（几块钱能聊很久）。
2. 左边「API Keys」→「创建 API Key」，复制那串 `sk-` 开头的字符。
3. 右键点角色 →「设置…」→「模型」→ 展开「DeepSeek」→ 粘贴 Key →「保存 Key」→「测试连接」。
4. 页面最上面「日常聊天使用」选「DeepSeek」。

也支持 Google Gemini、Claude API，以及任何「OpenAI 兼容接口」的服务（填地址、模型名、价格即可）。Gemini 和 Claude 在国内一般需要开代理，DeskMate 会自动使用系统代理设置。

### 没有 API Key，但有 Claude 订阅（Pro / Max）？
1. 先安装 Claude Code，在命令行里运行一次 `claude` 完成登录。
2. 「设置 → 模型」最上面「日常聊天使用」选「Claude Code（用订阅额度）」。
- 每条回复都要启动一次 claude，会比 API 慢几秒。
- 用的是订阅里单独的 Agent SDK 额度；DeskMate 只调用官方命令行，不会读取你的登录信息。
- 这种模式只能聊天，不能读写文件或执行命令。

## 三、换角色、换形象

- 右键角色 →「切换角色」，或者「设置 → 角色」。
- **用自己的图片**：「设置 → 角色」→ 点角色卡片 →「打开图片文件夹」，放入图片后点「重新加载」。
  - `idle.png` 待机（最重要；只放这一张的话所有状态都用它）
  - `talking.png` 说话、`thinking.png` 思考、`happy.png` 开心、`sad.png` 难过、`sleep.png` 睡觉（都可选）
  - 推荐约 320×360 像素、背景透明的 PNG；也支持 WebP / GIF / JPG，单张不超过 5 MB。
- 「禁词」和「自定义要求」（比如「回复不超过三句话」「叫我小林」）也在「设置 → 角色」里，可以对所有角色生效，也可以只对某个角色生效。
- **让红莉栖、千秋更像原作（可选）**：把原作的剧本、字幕或小说文本放进 `%APPDATA%\DeskMate\corpus\` 里对应的文件夹，再让 agent「炼化」：它会提炼她们说话的习惯、做成「台词库」。具体步骤见 `docs/NEEDS_USER.md` 第 7 项。这些材料只留在你自己电脑里。

## 四、记忆

- 角色会记住你在聊天里说过的重要事情（名字、喜好、正在做的计划……）。每次聊完一段时间后，在后台整理成「长期事实」和「聊天摘要」。
- **关于你的事所有角色都知道**；「你和某个角色之间发生的事」只有那个角色记得。
- 密码、验证码、身份证号、银行卡号、各种 Key **不会**被记住（会被自动隐藏）。
- 在聊天里说「**忘掉这件事**」「忘掉我住在哪」就能让它忘记。
- 「设置 → 记忆」里可以查看、搜索、修改、删除每一条记忆，也可以暂停记忆、导出、一键清空（需要输入「清空」确认）。
- 后台整理记忆用「设置 → 模型」里「后台整理记忆使用」的那个模型，建议选最便宜的。

## 五、提醒

- 在聊天里直接说：「半小时后提醒我收衣服」「明天早上 8 点提醒我交作业」「每周五晚上提醒我倒垃圾」「明天开机时提醒我带钥匙」「下次我开始打游戏的时候提醒我先写作业」。
- 她会复述一遍什么时候提醒你什么，你点「好」才会设上；不对就点「改一下」。没听懂时可以点「手动设置」自己填。
- 常见的说法不需要联网、不花钱（程序自己就能听懂），只有很少见的说法才会让模型帮忙理解一次。
- 电脑关着的时候错过的提醒，下次开机时会补上并告诉你是错过的。
- 玩游戏、看全屏视频时到了的提醒会改发 Windows 系统通知；标记为「重要」的提醒总会同时发系统通知。
- 右键角色 →「提醒…」或「设置 → 提醒」：查看、新建、编辑、暂停、删除。

## 六、每日播报

- 每天第一次打开电脑时，她会跟你说说今天的天气、是不是周末或节假日、吃什么、今天有哪些提醒；你的生日、纪念日那天会特别问候。每天挑的内容和顺序都不太一样。
- 想听天气：「设置 → 陪伴 → 你所在的城市」里输入城市名点「查找」（常用城市直接输中文，比如「上海」「大阪」；其他城市输英文或拼音）。城市只保存在你的电脑上，查天气时只发送这个城市的经纬度。
- 还可以加别的时间点，比如早上 8 点、晚上 11 点的「睡前问候」（说说明天的天气和提醒）；点「现在播报一次」可以马上听。
- 聊天里问「明天会下雨吗」「大阪冷不冷」，她也会去查天气再回答。
- 新闻（默认关闭）：在「新闻源」里打开或添加 RSS 地址，她会挑两三条标题说说。
- 有模型时整份播报只调用一次模型；没有模型或今天的额度用完时，用预先写好的台词说，照样能用。

## 七、她会注意你在做什么（活动感知）

- 她会看看你现在用的是什么程序（玩游戏、写代码、写作业、看视频……），偶尔说上一句：比如打完一大段游戏、玩了很久、深夜还在玩。窗口标题不会被保存，也不会发给模型。
- 密码管理器、网银、浏览器隐身窗口在前台时，她会暂时藏起来，什么都不记。还可以把别的程序加进隐私名单。
- 「设置 → 活动感知」：按类型或按程序设「可以评论 / 保持安静 / 回避」；查看、删除活动日志；也可以整个关掉。
- 日常关怀（「设置 → 陪伴」）：坐太久了、该喝水了、太晚了、到饭点了，每项都能单独关；你在玩游戏、看视频、开会时她会等一等再说。

## 八、她的心情、你们的关系、日记

- **摸摸头**：点角色的头（上面那一截）会有反应；点身体还是打开聊天；拖动她也会说两句。
- **心情**：聊天、摸头、一起玩、天气都会影响她的心情，过一阵子会慢慢回到平常。如果你放了对应的图片（`idle_good.png` 心情好、`idle_low.png` 心情差、`idle_rain.png` 下雨天、`idle_night.png` 夜里、`idle_summer.png` 夏天、`idle_winter.png` 冬天……），她待机时会换上。
- **亲密度**：每天相处会慢慢变熟（有每天上限，急不来），解锁新的称呼和台词；你多久不来都**不会下降**。「设置 → 陪伴」最上面能看到你们现在的关系，也能告诉她怎么称呼你。
- **随机小事件**：她偶尔会分享在想什么、问你个问题，或者给你几个选项选。
- **日记**：每天结束后她会写一篇短短的日记，在「设置 → 日记」里翻看。
- 告诉她「我的生日是 3 月 5 号」，她会记下来，那天特别问候你。

## 九、让她帮你打开、看看东西

- 聊天时说「帮我打开 B 站」「打开 D:\作业 这个文件夹」，她会在气泡里给出一个按钮，**你点了才会打开**。网页、文件夹、文档、图片、音视频都可以；程序和脚本不会直接打开，常用程序可以在「设置 → 高级」里登记一个名字，之后说「打开网易云」就行。
- 想让她看看某个文本文件写了什么：先在「设置 → 高级」里把那个文件夹加进「允许读取的文件夹」，然后在聊天里告诉她文件的完整路径，同样要你点一下「读取」才会读（只读，不会修改；文件内容会发给你用的聊天模型）。

### 高级：委托外部 agent（默认关闭）
DeskMate 现在是陪伴型的桌宠。如果你还是想让她把事情转交给 Claude Code / Codex，在「设置 → 高级」里打开「允许她把事情交给 Claude Code / Codex 去做」：

1. 需要先在电脑上装好并**登录一次** Claude Code 或 Codex（在命令行里运行 `claude` 或 `codex` 按提示登录）。
2. 把要处理的文件放进**任务文件夹**（默认 `D:\DeskMate-Work`，打开委托后在同一页下面可以改）。
3. 在聊天里跟角色说要做什么，它会先确认；你同意后会弹出一张「任务卡片」，点「开始执行」才会真正开始。
4. 安全规则：
   - 只能在任务文件夹里操作；
   - **删除文件、执行命令、联网、访问别的文件夹**之前会列出来让你逐条批准（Claude Code）；
   - Codex 默认只读，允许它改文件前会先把整个文件夹备份一份；
   - 每个任务有时间上限（默认 10 分钟）和花费上限。
5. 通过 Claude Code 执行任务会消耗你 Claude 订阅里**单独的 Agent SDK 月度额度**（不是聊天额度），用完会停止。
6. **不要在任务文件夹里放密码、证件照片、银行资料等敏感文件。**

## 十、花费与用量

- 「设置 → 用量与花费」可以看到每个模型用了多少、大约花了多少钱。
- 默认**每天最多 $1、每月最多 $10**，到了上限角色会告诉你并停止调用；可以自己调。
- 费用是按你填写的价格估算的，实际以服务商账单为准。

## 十一、日常设置（设置 → 常规）

- 总在最前、桌宠大小、待机小动画
- **全局快捷键**（默认 `Alt+Shift+D`）：随时唤出 / 收起聊天框
- 开机自动启动（默认关闭）
- 玩游戏、看全屏视频、演示时自动隐藏
- 多久没操作就睡觉
- 勿扰模式
- 「设置 → 陪伴」：她多久主动说一次话、安静时段、很久没聊天时打招呼（默认关闭）、主动说话每天最多花多少钱
- 「设置 → 高级」：显卡加速（默认关闭，这样更省内存；只有角色或聊天框显示不正常时才需要打开，退出 DeskMate 再打开后生效）

## 十二、隐私

- 聊天记录和记忆只保存在你电脑上：`%APPDATA%\DeskMate\deskmate.db`（在资源管理器地址栏输入 `%APPDATA%\DeskMate` 即可打开）。
- API Key 只保存在 Windows 凭据管理器里，不写进任何文件。
- 不收集任何使用数据，不自动更新。会连接的只有：你在「模型」里配置的服务（聊天内容会发给它）；选了城市后查天气用的 Open-Meteo（只发送经纬度）；你打开的新闻源。

## 十三、常见问题

**角色说「钥匙好像不对」/ Key 无效**：检查「设置 → 模型」里的 Key 是否完整、是否过期，点「测试连接」看具体错误。

**一直提示连不上网**：检查网络；Gemini / Claude 在国内需要开代理。点聊天框里错误下面的「查看详情」可以看到真实原因。

**问天气没反应 / 说不知道天气**：先在「设置 → 陪伴 → 你所在的城市」选好城市。
**问新闻、股价，角色说查不了**：聊天本身不能上网，角色也看不到实时信息（这是为了安全和省钱；天气是程序替她查的）。她会坦率说看不到，需要的话可以帮你打开相关网页。

**提示到了花费上限**：在「设置 → 用量与花费」里调高上限，或者等到第二天 / 下个月。

**角色不见了**：可能是开着全屏程序时自动隐藏了，或者被你隐藏了。点任务栏右下角托盘里的 DeskMate 图标即可显示；也可以按 `Alt+Shift+D`。

**角色或聊天框显示不正常（黑底、花屏、不显示）**：到「设置 → 高级」打开「显卡加速」，然后右键托盘图标退出 DeskMate，再重新打开。

**快捷键没反应**：可能被别的程序占用了，在「设置 → 常规」里换一个，比如 `Ctrl+Alt+K`。

**数据库损坏了怎么办**：DeskMate 每天自动备份（保留 7 份，在 `%APPDATA%\DeskMate\backups`），启动时发现损坏会自动从最近的备份恢复并提示你。

**怎么卸载**：Windows「设置 → 应用」里找到 DeskMate 卸载。聊天记录和记忆在 `%APPDATA%\DeskMate`，不想保留可以手动删掉这个文件夹；API Key 可以在「设置 → 模型」里先清除，或者在 Windows「凭据管理器」里删除 `DeskMate` 开头的条目。
